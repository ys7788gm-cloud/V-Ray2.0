# V-RAY 2.0

73개 농식품·스마트농업·푸드테크 평가업종을 적용한 공개형 기술가치평가 웹 도구입니다.

## 주요 기능

- 수익접근법, 로열티공제법 1·2 자동 계산
- 기술수명 영향요인과 기술기여도 평가정보 반영
- 73개 업종별 재무비율, WACC, 로열티율, 산업기술요소 자동 연결
- 업종통계·직접입력·CAPM·할인시점 등 선택 옵션
- 20년 이내 연도별 현금흐름과 현재가치 산출
- 시나리오 로컬 저장, JSON 가져오기·내보내기, 인쇄용 평가서
- 입력 내용은 서버로 전송하지 않고 사용자의 브라우저에서 계산

## 실행

```bash
npm install
npm run dev:pages
```

GitHub Pages용 정적 빌드는 `npm run build:pages`로 생성됩니다.

## 계산 원칙

기존 V-RAY 1.4.4의 수익접근법·로열티공제법·기술수명·기술기여도·WACC 구조를 준용했습니다. 공개 버전의 세부 산식과 데이터 처리 원칙은 [DATA_AND_METHOD.md](DATA_AND_METHOD.md)를 참고하세요.

## 주의사항

이 도구의 결과는 기술가치평가 검토를 지원하는 참고자료입니다. 공식 평가서 확정 전 평가전문가가 사업계획, 권리성, 시장성, 재무가정과 업종 적합성을 별도로 검토해야 합니다. 원본 통계 파일은 저장소에 포함하지 않습니다.
